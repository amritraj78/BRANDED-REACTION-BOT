### ⚙️ ENVIRONMENT VARIABLES

<details><summary>Tap On Me For Environment Variables</summary>

* `BOT_TOKEN` - (Required) Get from [@BotFather](https://t.me/BotFather)
* `OWNER_ID` - (Required) Your Telegram numeric User ID (e.g. `5423666218`)
* `OWNER_USERNAME` - (Optional) Your Telegram username without @ (default: `Villanns`)
* `SUPPORT_GRP` - (Optional) Support group username without @ (default: `amrit_feel`)
* `UPDATE_CHNL` - (Optional) Updates channel username without @ (default: `privatethink`)
* `MONGO_URL` - (Optional) MongoDB connection URI (leave empty for built-in in-memory DB)
* `GEMINI_API_KEY` - (Optional) Free Google AI Gemini API key
* `PORT` - (Optional) Web port for health checks (default: `8000`)

</details>

1. Click the **Deploy to Koyeb** button above or fork this repository to your **GitHub** account.
2. Sign up on [Koyeb.com](https://www.koyeb.com/) (Free Tier - no credit card required for standard free tier).
3. Click **"Create Web Service"** and select **GitHub**.
4. Choose your repository: `VIP-REACTION-BOT`.
5. Under **Builder**, select **Dockerfile** (or **Buildpack**).
6. Under **Environment Variables**, add:
   - `BOT_TOKEN`: Your Telegram Bot Token from [@BotFather](https://t.me/BotFather)
   - `OWNER_ID`: Your Telegram numeric User ID (`5423666218`)
   - `PORT`: `8000`
   - `KOYEB_PUBLIC_URL`: Your Koyeb app public URL (e.g., `https://your-app.koyeb.app`) *(Keeps free tier alive 24/7)*
   - `MONGO_URL`: *(Optional)* Leave empty for built-in in-memory database + Telegram backup
   - `GEMINI_API_KEY`: *(Optional)* Free Google Gemini key for smart AI
7. Under **Health Checks**:
   - Protocol: `HTTP`
   - Path: `/health`
   - Port: `8000`
8. Click **"Deploy"**! Your bot is now active 24/7 for life with automated keep-alive and 90% storage sentinel alerts!
